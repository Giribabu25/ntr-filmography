# ntr-filmography

The page is built as a cinematic tribute, combining a dark, premium aesthetic with clear data presentation.

Cinematic Visual Design: The deep charcoal background with vibrant orange-red gradients and glowing accents creates a modern, high-end feel. Each movie card uses a full-width photo with a subtle zoom effect on hover, giving the gallery a dynamic, film-like quality.

Clear Data Presentation: Box office figures and verdicts are presented in a clean, scannable format. The verdict badges are color-coded (gold for blockbuster, green for superhit, etc.) with distinct icons, making it easy to quickly assess a film's performance at a glance.

Responsive Layout: The grid adapts smoothly from a multi-column desktop view to a single-column mobile layout. Key information like the box office stats reflows for smaller screens, ensuring readability on any device.

Subtle Animations: Cards fade and slide in with a staggered delay for a premium loading experience. The hover lift effect adds a tactile, interactive quality that encourages exploration.

Optimization Tip: The movie posters are currently placeholder images from Unsplash. You can replace the src URLs in each .movie-poster img tag with actual movie posters for a more authentic and visually striking result.
